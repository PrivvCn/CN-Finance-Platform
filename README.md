# CN Finance

**Command. Navigate. Succeed.**

CN Finance is a financial management platform developed by CN, designed to help individuals and businesses organize, monitor and understand their financial activities.

## About the Project

CN Finance aims to simplify financial management through accessible technology and practical financial tools.

## Main Features

- Income and expense tracking
- Automatic balance calculation
- Financial performance analysis
- Profit, loss and break-even identification
- Transaction editing and deletion
- Financial data storage

## Technologies

- HTML
- CSS
- JavaScript

## Project Status

Currently under development.

## Vision

To evolve into a complete financial management platform, combining financial intelligence, technology and innovation.
